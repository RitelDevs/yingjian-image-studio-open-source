# 1.5.2 输入区与图片浏览补丁

本版本使用 1.5 的 API、账号及部署接口，未引入数据库结构或环境变量变更。

## 交互变化

- 风格方案两个选项与画面比例同行，专业优化仍按对话模型计费，生成仍需确认。
- 服务接受风格描述后，将文字和参考图保留在消息中并清空对应草稿。失败时不清空；等待期间的新草稿不会被旧请求覆盖。
- 图片默认进入大图浏览，浏览工具支持缩放、平移、下载和放入编辑台。来自会话的图片保留 threadId。

## 本地验证与发布

1. `npm run check` 检查接口、账号隔离、队列和既有功能。
2. `npm run build:published` 在本地构建生产前端和服务端。
3. `node scripts/check-compact-composer.mjs --origin=http://127.0.0.1:<端口>` 对已启动的静态前端执行全接口模拟的交互检查；不会访问真实用户账户或付费接口。
4. `npm run release:package` 生成允许公开的源码和部署包，保留私有环境配置、数据库、媒体、密钥在部署目标之外。
5. 部署前备份，排空现有队列，再替换编译产物。核验版本、域名 HTTPS、匿名访问保护、SSO 来源和账号数据保留。
