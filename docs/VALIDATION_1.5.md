## 1.5 编辑台浏览器验收

`check-editor-workspace.mjs` 在 1600px 桌面和 390px 移动视口运行，并拦截 API 为测试数据：

- 原图/编辑结果左右分屏，各自缩放及拖动，另一侧保持原位置。
- 框选裁剪、应用、撤销；参数数字直接输入。
- 工具栏打开编辑会话、适应画面。
- 会话图片带回原会话，无额外创建；会话选择器不受当前另一会话干扰。
- 刷新编辑草稿后仍识别图片来源；来源会话删除时保留编辑状态并显示失败。
- 本地上传重置来源，回传只新建一段会话；重复点击不会重复创建。
- 无生图/对话调用、无浏览器异常、无移动端横向溢出。
